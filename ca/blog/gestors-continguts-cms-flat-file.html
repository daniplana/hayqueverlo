Gestors de continguts Flat File

Breadcrumb

  1. Inici
  2. Blog

Es tracta de gestors de continguts (CMS) amb la base de dades emmagatzemada en arxius de text. No utilitzen servidors tipus SQL per a emmagatzemar els continguts. Així el seu consum de recursos del servidor on s’allotja son molt menors.

Tècnicament no es que siguin més segurs que els gestors de continguts que si utilitzen base de dades tipus MySQL, MariaDB, Mongo, etc. Però si que podem dir que com no tenen servidor per a la base de dades, aleshores ens estalviem els atacs dirigits específicament a servidors de bases de dades (mySQL injections).

Requereixen menys configuració i les copies de seguretat son més simples de realitzar. Tot està en arxius de text, que pots pujar per a restaurar i baixar per a tenir copies de seguretat. Inclòs alguns d’ells permeten fer-ho des de la pròpia web sense haver d’utilitzar FTP.

Existeixen molts més sistemes de gestió de continguts d’aquest tipus. Tots els que hem llistat a continuació amb software lliure i utilitzen servidors Apache2 amb PHP.

getgrav.org

Amb un backend molt treballat. Te un sistema de memòria cau, una instal·lació molt simple, es multi usuari i amb eines per a SEO. Utilitza per a desenvolupar Twig, Markdown, YAML, Symfony components i Doctrine Caching. De codi obert i amb llicencia MIT

gohugo.io

Hugo és un generador de webs estàtiques de codi obert, escrit en Go (Llenguatge de programació desenvolupat per Google). Està dissenyat per a crear webs ràpides i eficients, especialment blogs, documentació i portafolis, sense necessitat de servidores dinàmics. Hugo utilitza arxius Markdown i plantilles per a generar pàgines HTML, i destaca per la seva velocitat de compilació, flexibilitat per a gestionar contingut i l'amplia amplia varietat de temes. Es ideal per a desenvolupadors, escriptors i equips que vulguin una solució lleugera i fàcil de desplegar.

monstra.org

Utilitza arxius XML com base de dades. Amb plugins per a ampliar les seves funcionalitats i una bona interfície per a les eines de administració. Sota la llicencia MIT

FlatPress

Es un motor de blogs lleuger i fàcil de configurar. Simple i escrit només en PHP. ¡No necessita base de dades! FlatPress esta disponible des de 2006, es una plataforma consolidada i de provada eficàcia.

razorcms.co.uk

Amb la filosofia d’editar directament les pàgines, en lloc d’administrar a traves de panell d’administració. Utilitza PHP, AngularJS, Bootstrap i Font-Awesome. Utilitzant SQLite, per a emmagatzemar tota la informació en arxius. Amb llicencia GPL v3

get-simple.info

Basat en arxius XML per a la base de dades. Te plugins d’expansió i comunitat de desenvolupadors. Amb llicencia GPL v3

htmly.com

Desenvolupat per a ser simple i ràpid. Orientat a publicacions tipus blog. El seu disseny intenta Gastar el mínim de recursos del servidor on s’allotgi. Amb llicencia de software lliure GPL v2

bolt.cm

Utilitza Twig per el desenvolupament del disseny web i es totalment accessible des de mòbils. Inclosa la part d’administració. Aquest software te llicencia MIT.

automad.org

Desa les dades en arxius compressibles per a humans. Te un sistema de memòria cau de 2 passos que fan el web més ràpid. Amb llicencia MIT.
